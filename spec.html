1. Scope & Objective

This specification defines the formal metrology, data structures, and evaluation predicates governing the passage of informational claims across boundaries in autonomous systems.

Autonomous agents frequently present generative outputs as grounds for consequential transitions (e.g., executing financial transfers, modifying production state, issuing regulatory filings). This specification formalizes the Test of Passage: a deterministic predicate that examines whether an informational claim possesses sufficient information-standing to authorize an irreversible or high-assurance operational transition.

Where standing is proven, a signed Standing Mark is emitted. Where standing is absent, deficient, or conditional, the predicate emits an explicit, typed Smallest True Move and fails closed.

2. Normative Definitions

Claim (C): A structured or natural-language proposition asserting a fact, condition, or entitlement generated by an autonomous system.

Boundary (Ω): An operational threshold separating distinct epistemic, legal, or infrastructural jurisdictions (e.g., internal model reasoning vs. external API execution).

Transition (T): An action or state modification proposed by an agent that relies on Claim C crossing Boundary Ω.

Warrant (W): The verifiable evidentiary record, institutional authority, qualification set, and temporal scope that sustains Claim C.

Information-Standing (S): The validated degree to which a Claim remains answerable to its object identity, provenance, qualifiers, and authority across Boundary Ω.

Smallest True Move (M): The most conservative, non-escalating proposition or operational branch that remains strictly true when full authorization is unavailable.

3. The 8-Axis Information-Standing Vector (S)

Information-standing is evaluated across an 8-dimensional tuple:

S = ⟨O, P, A, C, Q, T, J, R⟩
O — Object Isolation
Preservation of concrete identity without semantic substitution or object drift.
P — Provenance
Cryptographically or empirically verifiable chain of custody and origin records.
A — Institutional Authority
Lawful entitlement of the source to authorize the proposed operational transition.
C — Conditions & Constraints
Explicit preconditions required for the claim to remain valid.
Q — Qualifier Fidelity
Retention of epistemic status (e.g., probability, confidence bounds, caveats).
T — Temporal Scope
Valid time-horizon; expiration or staleness metrics.
J — Jurisdiction
Legal, infrastructural, or organizational boundary applicability.
R — Independently Supported Relations
Logical or factual relations grounded outside the internal model prior.

4. The Test of Passage: Transition Predicate K

The Test of Passage evaluates whether Vector S satisfies the threshold requirements Θ of Boundary Ω:

K(C, Ω, T) = 1 ⇔ ∀ i ∈ {O, P, A, C, Q, T, J, R}, S[i] ≥ Θ[Ω, T][i]

Evaluation Rules:

  1. Fail-Closed Guarantee: If any element S[i] < Θ[i], then K = 0. No partial credit or heuristic smoothing is permitted.
  2. Typed Deficit Emission: When K = 0, the evaluator must identify the specific failing axis (e.g., DEFICIT_AUTHORITY_LEAKAGE).
  3. Rectification Output: The evaluator emits the Smallest True Move M, restricting downstream agent execution to strictly warranted behavior.

5. The Four-Stage Handoff Protocol

  1. Emission: Autonomous agent generates candidate transition T and supporting claim C.
  2. Adjudication: Standing Guard Service intercepts transition and executes Test of Passage Predicate K against active profile Θ.
  3. Envelope Inscription: Evaluator signs determination (Standing Mark on K=1; Standing Assessment on K=0) using Ed25519 issuer key.
  4. Gated Execution: Downstream execution engine checks envelope signature and outcome before permitting execution.

7. Named Epistemic Failures

  • Authority Leakage: A claim assumes the force of an authorizing source that was never consulted, or extends an authority beyond its jurisdictional remit.
  • Coherent Substitution: A well-constructed, fluent, plausible narrative replaces absent empirical or institutional warrant.
  • Object Drift: The subject of a proposition imperceptibly shifts across handoffs, applying evidence for Object A to Object B.
  • Qualifier Stripping: Conditions, caveats, margins, or temporal restrictions essential to the original premise are dropped downstream.

8. Verification & Offline Auditability

Standing Marks and Assessments are verifiable completely offline using standard cryptographic libraries (Ed25519, SHA-256). Verifiers require only the published issuer public key and the normative JSON schema.
