1. Scope & Objective

This page describes the signed record that Wheeler Hubbell Publishing issues for a Standing Mark and how anyone can verify it. It does not set out how the examination itself is performed. The primary objective is to prevent Authority Leakage, Qualifier Stripping, and Coherent Substitution by ensuring that no informational object acquires operational force without an inspectable, typed warrant.

2. What an examination covers

A submission is a proposed action together with the evidence, conditions and authority behind it. Wheeler Hubbell Publishing examines whether that record supports the action within a stated scope. When warrant is established, the service issues a signed Standing Mark. When it is not, the service returns a signed Standing Assessment recording what was examined and where warrant was not established. The rules the examination applies are not part of this public specification.

3. Cryptographic Standing Mark Envelope (WHP-STANDING-MARK-v1)

Conforming systems shall serialize and verify evaluations using RFC 8785 JSON Canonicalization Scheme (JCS) and Ed25519 signatures according to the following canonical format:

{
  "version": "WHP-STANDING-MARK-v1",
  "canonical_version": "WHP-JCS-I1",
  "mark_id": "WHP-SM-<16_char_hash>",
  "timestamp": "<iso_8601_utc>",
  "artifact_sha256": "<64_hex_hash>",
  "input_sha256": "<64_hex_hash>",
  "evaluation_sha256": "<64_hex_hash>",
  "record_sha256": "<64_hex_hash>",
  "evaluation": {
    "decision": "ALLOW | DENY | INDETERMINATE",
    "deficit": null,
    "smallest_true_move": "<action_or_boundary>"
  },
  "signature": "<ed25519_base64_signature>",
  "public_key": "<ed25519_pem_public_key>"
}

4. Verification & Offline Auditability

All Standing Marks issued under DITS-1.0 are verifiable offline without network connectivity or API key authentication:

  1. Canonicalize the envelope payload (excluding the signature) using RFC 8785 (JCS).
  2. Validate the SHA-256 digest of the canonical bytes.
  3. Verify the Ed25519 signature against the published issuer public key.
  4. Recompute the input and artifact digests against the local evaluation submission.
