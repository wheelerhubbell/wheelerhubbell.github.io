# Legacy Archive

This directory contains material that is historical, exploratory, or not part of the live canonical machine.

The canonical machine is:

- Wheeler Hubbell Publishing
- Decision Integrity Protocol
- Unilateral Integrity
- Standing Mark Service
- Standing Gate
- Standing Mark / Standing Assessment

## Legacy material intentionally archived

This archive intentionally captures material that may have been useful in earlier phases but no longer serves the current canonical system composition:

- exploratory essays and draft manuscripts
- legacy research fragments
- non-authoritative protocol notes
- historical service experiments
- demonstration proof artifacts not connected to the current runtime
- old design notes that are not part of the active protocol, runtime, or enforcement path

## Rule

If a document does not connect directly to the live canonical machine, it belongs in this archive and should not be treated as the authoritative system.
