# Canonical Machine and Archive

This repository is the public interface and canonical registry for the Wheeler Hubbell Publishing decision-integrity stack.

The canonical machine is not a bundle of detached essays, experiments, or historical notes. It is a single system:

- Wheeler Hubbell Publishing — the public brand and canonical identity
- Decision Integrity Protocol — the governing framework and ruleset
- Unilateral Integrity — the doctrine that a claim or action may not exceed the authority and provenance that justify it
- Standing Mark Service — the operational evaluation runtime
- Standing Gate — the enforcement layer for CI/CD and autonomous execution
- Standing Mark / Standing Assessment — the issued outcomes

## Canonical Scope

Only the following belong to the live canonical machine:

- public identity and brand surface
- protocol documentation and ruleset
- authoritative machine interfaces
- runtime service contract and verification flow
- enforcement gate and CI/CD integration
- standing mark and standing assessment records

Everything else is archival context or historical material, not the canonical machine itself.

## Archive

Legacy or non-authoritative material has been moved into the archive index under:

- `archive/README.md`
- `archive/legacy/README.md`

These files intentionally separate historical and exploratory material from the live canonical machine so that browsing the repo cannot confuse legacy fragments for the authoritative system.

## Operational Rule

The canonical machine is the only thing that defines the current identity of the system. Any material not directly connected to the current protocol, runtime, and enforcement path is considered non-authoritative and should not be treated as the system itself.
