# Wheeler Hubbell Canonical Machine

This repository is not a scrapbook and it is not a historical dump. It is the live public face of the current Wheeler Hubbell Publishing system.

The live canonical machine is exactly this:

- Wheeler Hubbell Publishing
- Decision Integrity Protocol
- Unilateral Integrity
- Standing Mark Service
- Standing Gate
- Standing Mark
- Standing Assessment

These are the only current canonical names for the system.

## Rule

A leaf cannot define the whole.

The system is defined only by the canonical root, not by any single file, document, or historical artifact.

If a file is not directly connected to the current canonical machine, it belongs under `archive/` and must not be mistaken for the live system.

## Scope

The current canonical scope is limited to:

- public identity and brand surface
- protocol documentation and ruleset
- runtime service contract and evaluation flow
- enforcement gate and CI/CD integration
- standing mark and standing assessment outcomes

## Archive rule

Everything else is archival context, not live system identity.

This includes:

- draft manuscripts
- exploratory essays
- historical notes
- non-authoritative experiments
- disconnected or legacy artifacts
- any material not directly tied to the active protocol, runtime, or enforcement path

## Enforcement

No assistant, workflow, or contributor should treat any single file or legacy artifact as the whole system.

The live canonical machine is the only authoritative definition of the current Wheeler Hubbell Publishing decision-integrity system.
