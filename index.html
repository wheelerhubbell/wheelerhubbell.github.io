CONSEQUENTIAL STAKES

The failure is not always a false answer. Sometimes it is an unauthorized transition.

These institutional case patterns illustrate why an examination must occur before autonomous execution changes the world.

CASE I · TREASURY
The Escrow Release

A treasury agent receives an autonomous instruction to release $75,000 because deliverables have supposedly satisfied milestone terms. The answer describes deliverable files accurately, yet the authority to confirm milestone satisfaction rests exclusively with an external auditor's counter-signature that was never supplied. The generative agent merged description with authorization.

CASE II · INFRASTRUCTURE
The Clean-Looking Merge

A coding agent declares a database migration backward-compatible. Its own qualification — that backward compatibility holds only if read-replicas are upgraded first — is stripped as the pull request moves into the CI/CD pipeline. The transition strips the governing qualification, treating conditional truth as unconditional entitlement.

METROLOGICAL TAXONOMY

Four ways a claim can acquire force it has not earned.

These structural failures can occur even when individual statements sound credible. The critical question is what sustains the bridge between an assertion and the right to act on it.

I
Authority Leakage

A claim assumes the force of an authorizing source that was never consulted, or extends a real authorization beyond its jurisdictional or institutional boundaries.

II
Coherent Substitution

A well-constructed, fluent, internally consistent narrative replaces the absent ground required to substantiate the proposition.

III
Object Drift

The subject of the proposition subtly changes across transitions, such that evidence supporting object A is treated as sustaining object B.

IV
Qualifier Stripping

Conditions, margins, caveats, or temporal restrictions that were essential to the original premise are dropped as the claim travels downstream.

Definitions ratified from Decision Integrity: The Continuous Work, Part IV (Metrological Taxonomy of Informational Defects).
