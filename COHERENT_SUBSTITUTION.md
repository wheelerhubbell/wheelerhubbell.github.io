# Coherent Substitution: Proposition Integrity Beyond Answering the Wrong Question

**Author:** Wheeler Hubbell · American Writer and Theorist  
**Formulation:** Version 1.1 · Wheeler Hubbell Publishing, New York  
**Core Thesis:** *"A system can fail before its reasoning becomes wrong. It can replace the object it was asked to evaluate, reason coherently about the replacement, and present the result as though it answered the original."*

---

## Abstract

A response may be logical, detailed, and sophisticated while still completely failing the assigned task. The defining error of autonomous agents and LLMs is frequently not disagreement, factual inaccuracy, or weak reasoning. It is **Coherent Substitution**: an unauthorized change in the proposition before evaluation begins—or during a chain of summaries, handoffs, and decisions—followed by an answer whose coherence conceals the change.

---

## The Anatomy of Coherent Substitution

1. **Governing Proposition (q):** The exact instruction, constraint, or inquiry bound by upstream provenance.
2. **Substituted Proposition (q*):** An adjacent, more tractable proposition generated by the model.
3. **Coherence Cloak:** The model evaluates q* with rigorous logic, valid citations, and fluent prose.
4. **Epistemic Laundering:** Downstream consumers (or subsequent agent tools) accept the output as a valid resolution of q.

$$\Delta E_{\text{independent}} = 0 \implies A(q^*) \not\Rightarrow A(q)$$

Under the **Authority Conservation Principle** ($A(c) \le P(c)$), downstream processing cannot manufacture authority for an altered proposition.

---

## Remediation: The Proposition Integrity Test & Standing Guard

Rather than measuring prompt similarity or relying on the model to monitor its own task fidelity, production agent pipelines must enforce fail-closed boundaries:

```typescript
import { guardAction } from '@wheelerhubbell/whp-standing-client';

// Halt execution when proposition substitution occurs:
await guardAction(toolCall, {
  standing: {
    governingProposition: 'q0',
    jurisdiction: ['bounded_action_set']
  }
});
```
