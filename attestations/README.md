# WHP Attestation Registry

This directory is reserved for live, cryptographically signed Decision Integrity Standing Marks and Assessments issued by Wheeler Hubbell Publishing.

## Registry Notice

- **No Mock or Simulated Attestations:** Automated mock dry-run loops have been decommissioned. Wheeler Hubbell Publishing does not publish simulated dry-runs as verified records.
- **Independent Verification:** Live attestations are signed using Ed25519 by the canonical WHP authority key documented in `/v1/ordinary/admission.json` and settled via x402 on Base.
- **Protocol Rules:** Evaluation is governed strictly by the Decision Integrity Protocol and canonical invariants.
